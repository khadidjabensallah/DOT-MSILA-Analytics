# Frontend Dashboard

This directory contains the React/Vite frontend application for the Algérie Télécom Analytics system.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

This interface connects directly to the FastAPI backend. Ensure you have the `VITE_API_URL` environment variable properly configured for production deployments.
